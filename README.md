Лабораторна робота № 2
Тема. Моделювання нейронних мереж. Перцептрон Розенблата.
Мережі Хопфілда і Хемінга
Мета роботи: Ознайомитися з нейронними мережами Хопфілда і Хемінга.
Застосувати нейронні мережі до задачі розпізнавання образів.

Завдання
1. Реалізувати систему розпізнавання перцептронного типу для випадку
двох класів
2. Розробити систему розпізнавання на базі штучної нейронної мережі Хопфілда
(та Хемінга)

Використаний фреймворк: Flask
Бібліотеки: Flask, NumPy, Pillow


Виконані завдання:

1. Попередня обробка зображень та вилучення ознак
- Перетворення зображень
-Формування векторів ознак
-Нормований та бінорний вектори

2. Перцептрон
-Реалізовано навчання одношарового перцептрона для бінарної класифікації
- Можливість налаштування гіперпараметрів користувачем: норми навчання (`learning rate`) та кількості епох (`epochs`).
- Динамічне оновлення вагових коефіцієнтів та зсуву (`bias`) у разі помилки класифікації.
- Фіксація історії навчання по кожному прикладу та визначення збіжності мережі (`converged`).
- Проведення розпізнавання тестового зображення за навченими вагами.

3. Хопфілд
- Реалізовано розпізнавання та відновлення образів на основі 3 еталонних зображень.
- Розрахунок матриці ваг
- Ітераційний процес
- Класифікація

4. Хеммінг
- Реалізовано класифікацію невідомого образу за 3 еталонними зображеннями.
- Перший шар (розрахунок відстані Хеммінга)
- Другий шар (MAXNET)
- Визначення підсумкового класу на основі найбільш активного нейрона після стабілізації 2-го шару.
